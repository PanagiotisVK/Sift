WHY THESE FIVE

=====================================================================
BEFORE YOU START — read this, it changes the order of operations
=====================================================================

The "best part" label over the waveform marker is shown EXACTLY ONCE PER INSTALL,
for 4.2 seconds, on the first card where the marker appears.

    index.html:4464    // Say what it is exactly once per install
    index.html:4465    if (!state.hotNamed) { ... setTimeout(remove, 4200) }

It is persisted to localStorage as `hotNamed`. You have already used the app, so
on your phone that flag is already set and the label WILL NOT APPEAR AGAIN.

That means shot 1 requires a FRESH INSTALL, and the whole session has to run in
order: delete the app, reinstall from TestFlight, then capture 1 -> 5 in sequence
as state accumulates.

  * Before deleting: if you are NOT logged in on your phone, your finds live only
    on the device and deleting the app loses them. Log in first, or accept the loss.
  * The label window is 4.2 seconds. SCREEN RECORD the first card, then pull the
    still frame out of the video. Do not try to time a tap.
  * Reduce Motion is on for you, so the marker appears without the drop animation.
    That is fine and actually steadier for a still.

=====================================================================
CAPTURE FORMAT — iPhone 17 Pro
=====================================================================
Device captures at 1206 x 2622. App Store Connect's 6.9" slot wants
1320 x 2868 or 1290 x 2796. Aspect ratios match (0.4600 vs 0.4603), so it is a
clean uniform upscale — no crop, no letterbox. Targeting 1290 x 2796 keeps it to
a 7% upscale. Confirm the accepted sizes in the ASC upload panel; Apple moves them.

STILLS vs VIDEO
  Shots 2, 3, 4 : still screenshots (side button + volume up). Full native quality.
  Shots 1, 5    : screen recording. These are transient — 4.2s and a loading state.
                  Do not try to time a tap.

Send the raw files, unedited and uncropped. Do not use the Photos app to trim,
mark up or "enhance" anything — it recompresses. AirDrop or upload the originals.

Tooling confirmed on this machine, so the whole pipeline is local:
  ffmpeg 8.1.1   frame extraction from the recordings
  Pillow 12.1.1  Lanczos upscale, caption compositing, exact output dimensions

STATUS BAR
The composite will get a clean status bar (full signal, full battery, 9:41) over
whatever the capture happens to show. This is standard practice and is what Apple's
own marketing does — 2.3.3 is about the app's screens being truthful, not the
carrier name. It also removes the screen-recording indicator if iOS burns one in.
